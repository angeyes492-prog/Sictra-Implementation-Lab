# Block 1 — Source Portfolio v0.1

`IMPLEMENTED CANDIDATE / LOCAL-TESTED / B`. E02 owns this bounded catalogue.
It exposes ten proposed logistics-source candidates across América, Europa,
Asia-Pacífico y Oceanía and reserves capacity for 50. It does not fetch,
verify, license, bind or treat any candidate as runtime evidence.

The local Workspace endpoint `GET /api/source-readiness?region=...&domain=...`
returns only `PROPOSED` candidates, explicit promotion blockers and
`admissible_source_count=0`. It accepts no URL, content, credentials, file or
configuration. Invalid queries fail closed.

Before any candidate becomes usable, a separately reviewed approval, allowlist,
claim authorization, access method and bounded source gateway are required.
