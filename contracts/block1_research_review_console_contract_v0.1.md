B4 exposes an explicitly configured, read-only view. Collection remains the
construction agent's separate action. Installed runtime networking stays disabled.

Observable objective: display a current exact quarantined statistical selection
alongside its official methodology, rights lineage and admission requirements.
Expose the actual missing input by need type without substituting an unrelated
root, approving the source or closing a task. No source or operations write.

Configuration requires an existing ResearchQuarantine and exact data and generic
methodology candidate IDs. Optional national and regional metadata each must
share the same current reuse-notice ID and hash. The regional receipt must use
the exact `EUROSTAT_REGIONAL_MAR_METADATA` recipe, never substitute for generic
or national metadata, and retains its original-byte hash and literal scope
label. Its absence is displayed as unconfirmed coverage, not silently omitted.
Directory enumeration, automatic selection, network
download, user supplied facts, source attestation and approval are excluded.

Each read recomputes the existing B1 admission review; its registration and
review requirements remain PENDING. The national review is separately identified,
never substituted for generic metadata or counted as another root. Re-read every
input, compare canonical bytes, reject clock regression and expire at the earliest
dependency boundary before returning. A missing, changed, substituted, expired or
malformed input exposes only UNAVAILABLE with no remembered measurements.
The HTTP consumer repeats canonical input/integrity and expiry checks after HTML
rendering and before emitting success headers; preparing a response cannot keep
an expired selection current. JSON responses use the same final fence.

Additive report version 0.2.0 includes nullable `regional_methodology`,
which is re-read and participates in the earliest expiry and final HTTP fence.
The HTML escapes and labels its publisher statement, including the explicit
limit that it cannot establish Statbel coverage equivalence or a numeric-gap
cause. Earlier configured views without a regional candidate remain read-only
and explicitly show that regional methodology was not supplied; no old
quarantine record or journal is migrated. Rollback omits the optional ID.

The console reports three separate needs: independent same-scope measurement,
release-specific revision explanation, and authorized company exposure. General
metadata may be available while the second need remains INSUFFICIENT EVIDENCE.
The panel labels publisher measurements QUARANTINED_NOT_ADMITTED and preserves
NOT_RESOLVED / NOT_ACCEPTED / runtime NONE / publication BLOCKED. It is not an
attested dossier or a consumer for E01–E08, B2 or B3. No task transitions follow.

Explicit candidate CLI configuration adds read-only loopback GET /research and
/api/research. Existing Host enforcement and no-store/security headers apply;
`serve --research-regional-id <exact-id>` selects the optional regional candidate
alongside required root/data/generic metadata arguments. It undergoes the same
initial validation before worker/server startup and every subsequent read fence.

sandbox CSP. Default server has NOT_CONFIGURED and no source data. Missing IDs,
partial configuration or malformed IDs reject before startup. Pause/STOP prevents
work but does not hide retained research; read currentness is checked regardless.

Compatibility: old operations data and routes are unchanged. The research view
has no journal or key and can be reconstructed from original candidate bytes.

Acceptance and installed UI adoption require MAR; this standalone lab view does
